# 有理數加法與乘法封閉性證明 — README




## 執行摘要  
本文件旨在嚴謹證明**有理數在加法及乘法下的封閉性**：即任意兩個有理數相加或相乘，其結果仍為有理數。加法部分以「循環節最小公倍數對齊與數位位置固定」為核心，先提出命題，再透過無進位與有進位的循環小數範例，以及特殊的無限9情況，逐步論證每一步仍可得到有理數。主要結論是：不論加法過程中是否產生進位，有理數加法仍屬封閉集。乘法部分簡述了逐位相乘的思路：將乘數的小數位逐一與被乘數相乘並適當移位，每項都是有理數乘積，有限多項之和可用加法封閉性證明有理；若遇無限循環小數，則利用循環節重複與等比級數的概念，證明無限和亦為有理數。總而言之，本文件通過實例演示與理論論證，完整展示了有理數對加法與乘法運算均屬封閉。

## 重要範例




以下以 `0.(12)` 表示 `0.121212...`，即括號內的 **12 整段無限循環**。所有範例皆使用 `[ ]` 標示完整的分組長度，避免循環線只覆蓋部分數字。




### 1. 無進位範例（共同分組長度 L = 6）




兩個加數為 `0.(12)` 與 `0.(123)`，循環節長度分別是 2 與 3。




**L = lcm(2, 3) = 6**，所以兩個加數都以 **6 位一組**：




```text
    0.[121212][121212][121212]...
  + 0.[123123][123123][123123]...
  --------------------------------
    0.[244335][244335][244335]...
```




每組相加：`121212 + 123123 = 244335`，沒有跨組進位。




**結果：`0.(12) + 0.(123) = 0.(244335)`**，仍為循環小數。




### 2. 有進位範例（不同循環節長度，L = 6）




為避免只用兩個相同長度的循環節，改取：




- 第一個加數：`0.(78)`，循環節長度為 2。
- 第二個加數：`0.(567)`，循環節長度為 3。




**L = lcm(2, 3) = 6**，兩個加數都以 **6 位一組**：




```text
    0.[787878][787878][787878]...
  + 0.[567567][567567][567567]...
  --------------------------------
    1.[355446][355446][355446]...
```




每組先相加：`787878 + 567567 = 1355445`，會向左進位 1。再加上右側一組傳來的進位 1：




```text
  787878 + 567567 + 1 = 1355446
                           ^^^^^^
                       保留 355446，向左進 1
```




因此每組保留 `355446`，進位固定為 1。




**結果：`0.(78) + 0.(567) = 1.(355446)`**，仍為循環小數。




### 3. 無限 9 範例（以長度 6 分組示範）




兩個加數都是 `0.(9) = 0.999999...`。它們的**最短循環節長度實際上是 1**；這裡為了展示「無限進位不會無限增加」，**刻意選用每 6 位一組**，並非聲稱最小公倍數是 6。




```text
    0.[999999][999999][999999]...
  + 0.[999999][999999][999999]...
  --------------------------------
    1.[999999][999999][999999]...
  = 2.000000000000000000...
```




每組相加 `999999 + 999999 = 1999998`；再加上右側傳來的 1，得到 `1999999`，保留 `999999`、向左進位 **1**。因此即使有無限多組，**每一組向左的進位仍然只是 1**。




由於 `0.999... = 1`，所以：




**結果：`0.(9) + 0.(9) = 1.(9) = 2`**，仍為有理數。




> 註：上述直式為循環區塊與進位規律的示意。無限小數沒有最右一位；無限 9 的結果可直接由 `0.999... = 1` 嚴格確認。




## 乘法段落摘要  
乘法證明採取逐位相乘、分段移位的方法：將乘數的小數部分逐位取出，每一位與被乘數相乘並適當地向右移位（相當於乘以10的冪），得到一系列的有理數項。由於有理數與整數相乘仍為有理數，每一項都是有理數；任意有限項之和也可依加法封閉性結論為有理數。然而若乘數或被乘數具有無限循環小數，會生成無限多項相加，此時需利用循環節重複的規律（或等比級數求和）來論證。循環小數的每一循環週期都類似，利用等比級數可計算出無限項的和仍是有理數。綜合而言，逐位相乘產生的無限項和亦屬有理數，從而證明有理數的乘法封閉性。
